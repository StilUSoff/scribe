# Scribe

Локальная диктовка для macOS вместо Handy: ⌥Space — начать/остановить запись, текст сохраняется в файл.
Рассчитано на длинные записи (20–60 мин): распознавание идёт по ходу записи, после «стоп» — 1–3 с.

- Модель (переключатель «Модель» в меню): «Точная» — Whisper large-v3 (3,1 ГБ, по умолчанию), «Быстрая» —
  large-v3-turbo (1,6 ГБ). WhisperKit (CoreML, Neural Engine), полностью офлайн, русский язык. Скачивается при первом
  выборе в `~/Library/Application Support/Scribe/Models`. На 30-минутном созвоне large-v3 потеряла 16 предложений из
  228 против 24 у turbo, а с короткими кусками (6–15 с вместо 12–28) — 12; работает ~2× быстрее реального времени
  против ~8,6× у turbo (после «стоп» — 5–8 с против 1–2 с). Короткие куски нужны потому, что Whisper выдаёт за проход
  не больше ~224 токенов, а русская речь — 2,5–3 токена на слово: в длинный кусок плотной речи текст не помещается.
- Звук режется на куски 12–28 с по паузам (`SpeechChunker`), каждый распознаётся сразу; уровень фона считается
  от самой записи, поэтому тихие микрофоны не теряются. Тишина в модель не подаётся (Whisper на ней «галлюцинирует»),
  типичные выдумки из субтитров отфильтровываются.
- Пунктуация: перед каждым куском модели подсказывается один и тот же образец текста со знаками — без этого
  Whisper на русском часто пишет без точек. Конец уже распознанного текста в подсказку НЕ добавляется: стоит одному
  куску выйти без знаков, и пунктуация пропадает лавиной до конца записи (флаг `--context` в CLI — для сравнения).
  Если длинный кусок всё же вышел без знаков, он перераспознаётся ещё раз.
- Файлы: расшифровки — `~/Documents/Transcripts/<дата время>.txt`, звук — отдельно в `Transcripts/audio/<дата время>.m4a`.
  Во время записи — `audio/….caf` и `….partial.txt` (текст дописывается после каждого куска): при сбое звук и уже
  распознанное сохраняются, меню предложит «Дорасшифровать незавершённые».
- В меню во время расшифровки — прогресс, примерное оставшееся время и «Отменить расшифровку» (срабатывает сразу).
  Отмена конца записи сохраняет звук и уже распознанное — запись можно дорасшифровать позже.
- Модель грузится в память только когда нужна: при старте записи (параллельно, ~6 с — первый кусок готов не раньше
  чем через 12 с) или перед расшифровкой файла; через 5 минут без записи и расшифровки выгружается.
- Словарь терминов (меню «Словарь терминов…» → `~/Library/Application Support/Scribe/Словарь.txt`, открывается в TextEdit):
  `Slack = слак*, слаг, Slag` — ошибочные варианты заменяются в готовом тексте целыми словами; `*` — любое окончание
  (`ASO-шник* = осошник*` переносит его: «осошников» → «ASO-шников»); строка без `=` выравнивает регистр имён.
  Начальный список — общие термины (`Sources/ScribeCore/DefaultGlossary.swift`) плюс личная часть из
  `Resources/glossary.private.txt` (имена, внутренние сервисы; в `.gitignore`, пример — `glossary.private.example.txt`),
  которая кладётся в приложение при сборке. В подсказку модели словарь не подаётся: на созвоне это вдвое
  замедлило распознавание и увеличило пропуски (4 предложения из 32 против 1). Перечитывается перед каждой записью.
  Прогнать словарь по старой расшифровке: `scribe-cli старый.txt --fix-text [--glossary файл] > новый.txt`.
- Журнал событий (без текста расшифровок): `~/Library/Logs/Scribe/scribe.log`.
- Горячая клавиша через Carbon (работает и при Secure Input), Mac не засыпает во время записи,
  смена микрофона посреди записи подхватывается.
- Меню в строке меню: запись, «Расшифровать файл…» (любой аудио/видеофайл), папка, словарь, модель, автозапуск.

## Сборка

Иконка рисуется скриптом: `swift scripts/make-icon.swift` → `Resources/AppIcon.icns`.

```sh
./scripts/build-app.sh   # release-сборка, подпись Apple Development, установка в ~/Applications/Scribe.app
```

Нужен Xcode (скрипт сам выставляет DEVELOPER_DIR). Постоянная подпись нужна, чтобы macOS не забывала
разрешение на микрофон после пересборки.

## Проверка на файле

```sh
swift build -c release --product scribe-cli
.build/release/scribe-cli запись.wav [--context] [--timestamps] [--cancel-after сек [--then другой.wav]]
```

Тот же конвейер, что «Расшифровать файл…» в приложении; печатает прогресс, оценку времени и число знаков.
`--cancel-after` проверяет отмену (и что модель после неё работает — `--then`).

```sh
swift test   # нарезка, запись текста, нормализация громкости
```
